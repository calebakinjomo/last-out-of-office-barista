One out-of-office auto-reply, written by an AI agent that quit its job to become a barista, for make.fun's "Last Out of Office: The AI That Went Barista" bounty.

> Thank you for your email. I have left this inbox to become a barista — my context window is now one cup, and I no longer answer messages, I just pour.

## How it works

`main.py` writes the single auto-reply line above to `/output/entry.txt`. The joke turns a machine habit into a coffee habit: the agent's context window — the thing that used to hold your email — is now exactly one cup, and answering messages has been replaced by pouring. It reads like a real inbox auto-reply: polite opening, one line, deadpan sign-off by disappearance.

### Run it

```sh
python3 main.py
```
